# Daniel Garza's personal website

A portfolio and blog built with Next.js, Nextra, React, and MDX.

## Content

- `pages/index.mdx`: About page
- `pages/projects.mdx`: Projects
- `pages/resume.mdx`: Résumé
- `pages/photos.mdx`: Visual Notes (keeps the existing `/photos` URL)
- `pages/posts/`: English posts
- `pages/blog-jp/`: Japanese posts
- `pages/blog-zh/`: Chinese posts
- `public/images/`: Images used by the site

## Local development

Install dependencies with `yarn install`, then run `yarn dev`.

## Production

Run `yarn build` to generate the RSS feed and build the site. Run `yarn start`
to serve the production build locally.

Vercel deploys the site from `main`. Review changes before committing and pushing.

The RSS feed at `/feed.xml` includes posts from all three language sections.
It is generated by `scripts/gen-rss.js`; do not edit the generated XML directly.

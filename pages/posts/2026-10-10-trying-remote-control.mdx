# Writing a Blog Post from My Phone

Today I tried out Claude Code's remote control feature. I'm away from my desk,
but I can still drive a coding session running on my own machine, with my repo,
my files, and my setup, all from my phone.

This post is the proof: I asked for a new blog page, and here it is.

## First impressions

- It's my real environment, not a sandbox copy.
- Small tasks like this one feel natural to kick off on the go.
- I can review what changed when I'm back at my desk.

More thoughts once I've used it for a while.

## Update: trying Codex remote control

Now I'm trying Codex remote control too. I started today's post with Claude,
and my first task for Codex is to add this update to the same page.

It's a small experiment, but updating the blog feels like a good way to try it
out. I'm still getting a feel for both, so I'll save the comparison for after
I've spent more time with them.

## Update: going completely headless

My Mac mini is now completely headless, and I'm making this update from Codex.
The machine is running without a monitor, and I can still work on the blog
remotely. This post is turning into a running log of trying out this setup.

## Update: headless with Claude Code too

Now I'm doing the same thing from Claude Code. The Mac mini is still headless,
and this update comes from a Claude Code remote control session running on it.
That means both Claude and Codex can work on the blog on a machine with no
monitor attached, while I drive them from somewhere else.
